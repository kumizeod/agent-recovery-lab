# Roadmap / 后续可慢慢做

当前目标仍是保留小而清楚的基础。已追加 Chat Completions 工具循环和真实 CSV 后台 worker；以下是尚未完成的扩展。

## 近期

- 扩展公共工具返回 schema；已有模型输入参数 schema 和严格检查。
- 用实际模型端点验证当前 adapter，记录能力和兼容性边界。
- 用独立进程运行 Agent，增加硬超时和资源清理。
- 增加新的 CSV 处理类型；当前只支持固定去重 worker。
- 明确持久化、重启、异常处理和原始数据访问规则。

## 环境逐步扩展

- schema 校验、单位转换、关联、聚合等独立任务家族。
- 作业失败、错误产物、部分产物、延迟提交、过期状态。
- 按模板和故障组合划分数据，人工审计评分规范。
- 真实使用者可以新增一种任务并运行自己的策略。

## 评测与训练

- 基于 Verifiers 的薄适配，固定兼容版本。
- 选一条训练栈，优先验证 prime-rl 的最小配置。
- 原始模型 / 强规则基线 / SFT / SFT+RL 的对照。
- 检查显存、rollout 长度、上下文、训练速度与预算，不预设单卡可跑所有配置。
- 必须完成真实运行与保留集评测后，才写模型效果或求职量化数字。

## 暂时不做

多云调度、Kubernetes、通用多 Agent 框架、复杂前端、生产系统连接、自动发布代码、机器人适配、大规模排行榜。
